> 依据任务书 "(1).md" 修订版三关剧本整理，并已与 2026-09-08 最新代码（backend/state.py + scene_map.json）对齐。  
> 共 **23 张必生成 + 4 张可选状态变体**。  
> 物品图标（🔑 ⚙️ 🧾 🐟 🧲 🗝 📜）使用 emoji，**不需要生成图片**。

## 一、目录与命名规范（直接对应 scene_map.json / state.py）

```
assets/
├── study/        第 1 关 旧书房
├── living_room/  第 2 关 客厅
├── garage/       第 3 关 车库
└── prompts/      本清单文档
```

命名规则：全景图 `{room}/panorama.png`，特写图 `{room}/{object_id}.png`，全部 16:9、1600×900。  
当前各目录下为同名 SVG 占位图，批量出图后按同名替换为 PNG 即可，**零改代码**。

## 二、统一风格模板（铁律：每张提示词 = 前缀 + 主体描述 + 后缀）

**前缀（风格）**：

> 扁平数字插画风格，暖色低饱和调（棕、墨绿、暗金），柔和体积光，细腻阴影，卡通写实质感，密室逃脱游戏场景美术，画面干净无文字无边框

**英文版（文生图模型建议用英文主体+英文风格）**：

> flat digital illustration, warm muted palette (brown, dark green, dim gold), soft volumetric light, detailed shadows, semi-realistic cartoon game art, escape room scene, clean composition, no text, no letters, no people, 16:9

**后缀（构图）**：

> 单一主体居中构图，四周留白边距，均匀打光，无水印

> ⚠️ **风格待定稿**：2026-09-08 已按用户要求生成第 1 关书房全景示例（白底简洁风，  
> `study/Minimalist_flat_illustration_o_*.png`）。若定稿"白底简洁风"，请把上面前缀整体替换为：  
> 「扁平极简插画，白色主导背景（亮白墙面、浅灰柔和阴影），细线描边，柔和点缀色，大量留白，密室逃脱游戏场景美术，画面干净无文字无边框」，  
> 并三关统一重出。批量生成前先确认风格。

**三条硬规则**：

1. **图内禁止出现文字/数字**——AI 生成中文文字必然乱码。所有纸条、贴纸、背板上的文字，由前端在特写图上叠加 HTML 文字框显示（图文对齐由代码保证，不靠模型）。
2. 全景图中各对象的位置、外观必须与对应特写图一致（同款式、同颜色），避免图文错位。
3. 一次性批量生成，不要分批改风格。

## 七、生成与接入流程

1. 按"前缀 + 主体 + 后缀"拼接完整提示词，一次性批量生成（建议先各生成 1 张小样确认风格统一，再补齐）。
2. 图片直接存入上表对应路径（PNG，1600×900，16:9），同名替换现有 SVG 占位图。
3. 图片路径以后端 `backend/state.py` 的 `closeup_image` 为唯一真源（`scene_map.json` 与之保持同步），AI 只能切换已存在的对象图，不能自由指定图片。
4. 逻辑未跑通前不急生成——先出图占位色块（本清单先行锁定 ID 与文件名，保证后期替换零改代码）。
