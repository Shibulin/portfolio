# 医道求真 · 中医卡牌合成游戏

以《本草纲目》为背景的 2D 卡牌合成游戏。玩家扮演小医，在药师李时珍的指导下辨识草药、合成药方，为病人诊治疗疾。

> 广东工业大学《游戏开发原理》课程设计，3 人团队合作完成。

## 玩法

- **卡牌合成**：22 种草药卡 → 按特定组合合成 6 种药方卡（四君子汤、六味地黄丸、四物汤、银翘散、麻黄汤、桂枝汤）
- **治疗**：将药方卡拖给对应病症的病人 —— 正确 +10 分，错误 −5 分
- **两种模式**
  - 普通模式（限时）：倒计时内尽可能多地治愈病人
  - 无限模式：累计 3 次错误治疗即结束
- **提示与反馈**：点击李时珍头像获取提示；治疗正确 / 错误时角色有对应反应

## 运行

1. 安装 Unity Hub，添加编辑器版本 **2022.3.33f1c1**
2. 用 Unity Hub 打开本目录（含 `Assets/`、`Packages/`、`ProjectSettings/`）
3. 打开 `Assets/Scenes/` 中的场景文件运行

> 仓库不含 Unity 自动生成的 `Library/`、`Temp/` 等缓存目录，首次打开需等待 Unity 重新导入资源。
